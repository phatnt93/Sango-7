```text
Sango7/
├── Sango7.exe
├── Patch.PCK
└── Setting/
    ├── SystemText.ini
    ├── TermText.ini
    ├── GossipText.ini
    ├── GameText.ini
    └── ... cac file .ini da dich khac
```
